Método 1: Netlify Drop

El más rápido del planeta. Arrastrás, soltás, compartís.

✅
Tiempo total estimado: 3 minutos la primera vez, 30 segundos después.
No necesitás instalar nada ni crear cuenta para empezar.

Paso a paso

1
Obtener el archivo HTML de Claude o ChatGPT
El artefacto que generó la IA necesita guardarse como archivo
▾

En Claude:

  1. Cuando Claude genera un artefacto (la ventana de preview a la derecha), buscá el ícono de descarga o los ... arriba a la derecha del artefacto.
  2. Hacé clic en "Download" o "Descargar".
  3. Se guarda un archivo .html en tu carpeta Descargas.

En ChatGPT:

  1. ChatGPT muestra el código en el panel derecho.
  2. Copiá todo el código (Ctrl+A → Ctrl+C dentro del panel).
  3. Abrí el Bloc de Notas (Windows) o TextEdit (Mac).
  4. Pegá el código y guardá como: mi-agente.html
    ⚠️ Importante: asegurate que la extensión sea .html y no .txt
💡
Podés pedirle a Claude directamente: "Descargame esto como archivo HTML listo para publicar" y lo generará como artefacto descargable.
2
Ir a Netlify Drop
La plataforma que hace toda la magia
▾

Abrí en tu navegador: app.netlify.com/drop

Vas a ver una gran zona punteada que dice "Drag and drop your site folder here".

ℹ️
¿Un solo archivo o una carpeta? Si tu agente es un único .html (lo más común), podés arrastrarlo directamente. Si tiene imágenes, CSS separado u otros archivos adicionales, ponelos todos en una carpeta y arrastrá la carpeta.
3
Arrastrar y soltar el archivo
Drag & drop → magia
▾
  1. Localizá tu archivo mi-agente.html en el Explorador de archivos (Windows) o Finder (Mac).
  2. Arrastralo encima de la zona punteada de Netlify.
  3. Soltalo.
  4. Esperá unos 10-20 segundos mientras sube.

Netlify te va a mostrar una barra de progreso y luego... 🎉

4
Copiar y compartir tu URL
El link que vas a mandar a tus docentes
▾

Netlify te genera automáticamente una URL del tipo:

https://nombre-random-123456.netlify.app

Hacé clic en "Copy link" y mandásela a quien quieras. Listo. Funciona en celular, tablet y computadora.

⚠️
Duración sin cuenta: Los deploys sin cuenta duran solo 24 horas. Para tenerlo permanente, creá una cuenta gratuita en Netlify (con tu email) y reclamá el sitio. Con cuenta: permanente y gratis.
+
Opcional: personalizar la URL
Cambiar "nombre-random-123456" por algo más memorable
▾

Con cuenta gratuita en Netlify podés renombrar el subdominio:

  1. Ingresá a tu dashboard en netlify.com
  2. Hacé clic en tu sitio → Site settings
  3. En "Site information" → "Change site name"
  4. Escribí, por ejemplo: gemelo-ubp

Tu URL queda: https://gemelo-ubp.netlify.app — mucho más presentable para compartir con colegas.

🐙

Método 2: GitHub Pages

La opción profesional y permanente. Inversión inicial de 20 minutos, beneficio eterno.

ℹ️
¿Qué es GitHub? Es como Google Drive pero para código. GitHub Pages es su funcionalidad gratuita para publicar páginas web. Lo usan universidades de todo el mundo para publicar materiales educativos.
Crear cuenta GitHub
→
Crear repositorio
→
Subir HTML
→
Activar Pages
→
¡URL lista!
1
Crear tu cuenta en GitHub
Una sola vez. Gratis.
▾
  1. Ir a github.com
  2. Clic en Sign up
  3. Elegí un username (te sugiero algo como waldo-ubp o catedra-ia-ubp)
  4. Completá el registro con tu email institucional
🎓
Con email .edu podés solicitar GitHub Education que da beneficios extra (aunque para este uso no los necesitás).
2
Crear un repositorio nuevo
El "contenedor" donde van tus archivos
▾
  1. En tu dashboard, clic en el botón verde "New" (arriba a la izquierda)
  2. Repository name: ponele el nombre de tu proyecto, ej: agentes-ia-ubp
  3. Asegurate que esté en Public (necesario para GitHub Pages gratis)
  4. Tildá "Add a README file"
  5. Clic en "Create repository"
3
Subir tu archivo HTML
Sin línea de comandos, todo desde el navegador
▾
  1. Dentro de tu repositorio, clic en "Add file" → "Upload files"
  2. Arrastrá tu mi-agente.html al área de carga
  3. Importante: si querés que sea la página principal, llamá al archivo index.html
  4. Abajo en "Commit changes" dejá el mensaje predeterminado o escribí algo como "Subir agente IA"
  5. Clic en "Commit changes"
💡
Podés subir múltiples archivos HTML. Cada uno tendrá su propia URL dentro del mismo repositorio.
4
Activar GitHub Pages
El paso que lo convierte en sitio web público
▾
  1. En tu repositorio, ir a Settings (la rueda dentada en el menú superior)
  2. En el menú lateral izquierdo, clic en Pages
  3. En "Source", seleccioná "Deploy from a branch"
  4. En "Branch", elegí main y la carpeta / (root)
  5. Clic en Save
  6. Esperá 1-2 minutos (podés recargar la página)

GitHub Pages te mostrará tu URL:

https://tu-usuario.github.io/nombre-repo/

Ejemplo real: https://waldo-ubp.github.io/agentes-ia-ubp/

+
Actualizar el agente con una nueva versión
Cuando mejorés el HTML, el link sigue igual
▾
  1. Entrá al repositorio
  2. Hacé clic en el archivo que querés reemplazar
  3. Clic en el ícono del lápiz ✏️ (Edit)
  4. Borrá todo y pegá el nuevo código HTML
  5. Clic en "Commit changes"
  6. En 1-2 minutos el sitio se actualiza. El link NO cambia.
🎯
Esta es la gran ventaja de GitHub Pages: actualizás el contenido pero el link que mandaste a tus docentes sigue funcionando.

Método 3: Vercel

La opción para cuando tenés varios proyectos y querés actualizarlos seguido.

ℹ️
¿Cuándo elegir Vercel sobre GitHub Pages? Cuando tenés 5+ agentes diferentes, los actualizás frecuentemente, o querés un dashboard centralizado para gestionar todo desde un solo lugar.
1
Crear cuenta en Vercel
Lo más fácil: usás tu cuenta de GitHub
▾
  1. Ir a vercel.com
  2. Clic en "Sign Up"
  3. Elegí "Continue with GitHub" (esto conecta ambas cuentas automáticamente)
2
Importar tu repositorio de GitHub
Vercel lo detecta y lo publica solo
▾
  1. En el dashboard de Vercel, clic en "Add New Project"
  2. Vercel muestra tus repositorios de GitHub
  3. Elegí el repo con tus agentes
  4. Clic en "Deploy"
  5. En 30 segundos tenés la URL

Tu URL será algo como:

https://agentes-ia-ubp.vercel.app
🤖
Auto-deploy: Cada vez que actualizás un archivo en GitHub, Vercel lo detecta y redespliega automáticamente en segundos. El link sigue igual.
💡
Flujo recomendado combinado: Usá GitHub para guardar tus archivos (como control de versiones) y Vercel para publicarlos. Cuando mejorés un agente en GitHub, Vercel lo actualiza solo. El link que le mandaste a tus docentes siempre funciona.
🌐

Bonus: Dominio propio gratuito o de bajo costo

Para cuando querés algo como agentes-ia.ubp.edu.ar

⚠️
Esto requiere coordinación con el área de sistemas de UBP. Si UBP ya tiene su dominio ubp.edu.ar, pueden crear un subdominio gratis. Pero también podés conseguir tu propio dominio por muy poco.

Opciones para dominio propio

A
Subdominio UBP (coordinación institucional)
algo.ubp.edu.ar — la opción más profesional
▾

Si UBP tiene control sobre su DNS (muy probable), pueden crear un subdominio gratuito como:

ia-catedra.ubp.edu.ar

Necesitás pedirlo al área de sistemas y darles los datos de tu plataforma (Netlify o Vercel). Ellos configuran el DNS y listo. El hosting sigue siendo gratis en Netlify/Vercel.

B
Dominio .com.ar por tu cuenta
Bajo costo, independencia total
▾

En Argentina, un dominio .com.ar cuesta aproximadamente $2.000-$4.000 ARS por año (muy poco). Podés registrarlo en:

  • nic.ar — el registro oficial argentino
  • NicAr, DonWeb, Cloudflare Registrar (para .com internacional)

Después conectás el dominio a tu sitio en Netlify, Vercel o GitHub Pages desde la configuración de DNS.

💡
Cloudflare ofrece dominios .com a precio de costo (~USD 10/año, sin markup). Para dominios .ar podés usar Cloudflare también si lo registraste antes en otro lado.
C
Conectar dominio propio a Netlify (sin código)
El proceso de configuración
▾
  1. En Netlify: Site settings → Domain management → Add a domain
  2. Escribí tu dominio (ej: agentes-ia.com.ar)
  3. Netlify te da dos registros DNS que tenés que copiar
  4. Entrás al panel donde registraste tu dominio (nic.ar, DonWeb, etc.)
  5. Buscás la configuración DNS y cargás esos registros
  6. Esperás entre 10 minutos y 24 horas (propagación DNS)
  7. Netlify activa el HTTPS automáticamente, gratis

El flujo completo: de la IA a tus docentes

El proceso de punta a punta para cualquier artefacto

Flujo recomendado para la Cátedra

1
Generás el artefacto con Claude o ChatGPT
Con el prompt adecuado para obtener HTML listo para publicar
▾

Cuando pedís un artefacto web, asegurate de incluir en tu prompt:

Crea esto como un archivo HTML completo, autocontenido (sin dependencias externas), con CSS incluido en el mismo archivo. Que funcione al abrirlo directamente en un navegador sin necesidad de servidor.

Los artefactos "autocontenidos" son los más fáciles de publicar porque son un solo archivo.

2
Descargás el HTML
Guardar el artefacto como archivo local
▾

En Claude: botón "Download" en el artefacto.
En ChatGPT: copiar el código y pegar en Bloc de Notas, guardar como .html.

📁
Organizá tus artefactos en carpetas por tema: Agentes/Simuladores/, Agentes/Guias/, etc. Así cuando los subís a GitHub están ordenados.
3
Probás localmente antes de publicar
Abrís el archivo en el navegador como control de calidad
▾

Antes de compartir, hacé doble clic en el archivo .html. Se abre en tu navegador y podés verificar que funciona correctamente. Si algo no anda, volvé a Claude con el problema.

Este agente tiene un error: [describí el problema]. Aquí está el código actual: [pegá el HTML]. Corregilo manteniendo el resto igual.
4
Publicás con el método elegido
Netlify Drop para urgencias, GitHub Pages para todo lo demás
▾

Regla simple:

  • ¿Necesitás el link en los próximos 5 minutos? → Netlify Drop
  • ¿Va a durar más de un día o lo vas a actualizar? → GitHub Pages
  • ¿Tenés muchos proyectos y querés automatización? → GitHub + Vercel
5
Compartís el link con tus docentes
El paso final (¡y el más fácil!)
▾

Copiás la URL y la mandás por WhatsApp, email, Campus Virtual o la clavás en una presentación de PowerPoint como código QR.

📱
Para generar un QR del link, podés usar qr.io o simplemente pedirle a Claude: "Generá un QR de esta URL: [tu link]" y te da el código para incluirlo en tu slide.

Preguntas frecuentes

Las dudas que van a aparecer, respondidas antes de que aparezcan

?
¿Es realmente gratis? ¿Hay letra chica?
▾

Netlify: Gratis hasta 100GB de ancho de banda/mes y 300 minutos de build. Para materiales educativos estáticos (HTML puro), es prácticamente imposible superar ese límite.

GitHub Pages: Gratis sin límite de tiempo para repositorios públicos. Límite de 1GB por sitio y 100GB de ancho de banda/mes. Más que suficiente.

Vercel: Plan gratuito (Hobby) incluye proyectos ilimitados con algunas restricciones. Para uso académico no comercial, el plan gratis alcanza.

?
¿Qué pasa si el artefacto usa IA por dentro (llama a la API de Claude)?
▾

Si tu artefacto hace llamadas a la API de Claude o ChatGPT, el HTML publicado necesita una API key. Hay dos opciones:

  • Incluir la key en el HTML (no recomendado): Cualquiera que vea el código fuente la puede robar.
  • Pedir la key al usuario (recomendado para docentes): El artefacto le pide a cada usuario que ingrese su propia API key. Así cada docente usa su propia cuenta.
Modificá este artefacto para que al abrirse le pida al usuario su API key de Anthropic antes de funcionar. Que la guarde en localStorage para no pedirla de nuevo.
?
¿Los docentes necesitan cuenta para usar el artefacto?
▾

No. Una vez publicado, cualquier persona con el link puede abrir el artefacto en su navegador. No necesitan crear ninguna cuenta. Es exactamente igual a abrir cualquier página web.

?
¿Cómo sé si el agente está funcionando después de publicarlo?
▾

Abrí el link en una pestaña de incógnito (Ctrl+Shift+N) y probalo como si fueras un docente. La pestaña incógnita simula un usuario nuevo sin caché previo.

También podés mandarle el link a alguien con un dispositivo distinto (celular vs computadora) para verificar que funciona cross-device.

?
¿Puedo poner contraseña para que solo accedan mis docentes?
▾

Netlify tiene una función de password protection en el plan gratuito (básica). También podés pedirle a Claude que genere un HTML con login simple por contraseña incorporado en el propio código (no es seguridad real, pero filtra accesos casuales).

Añadí una pantalla de login al artefacto. Contraseña: "ubp2025". Si es correcta, muestra el contenido. Que sea simple y se vea bien.
?
¿Puedo publicar los artefactos que genera Claude directamente, sin descargar?
▾

Los artefactos de Claude tienen links temporales que no están pensados para compartir externamente (duran poco y requieren estar logueado en Claude). Por eso el flujo correcto es descargar el HTML y publicarlo vos en tu propia plataforma.

Netlify está trabajando en integraciones directas con IAs, pero por ahora el proceso manual de 2 pasos (descargar → subir) es lo estándar.

🚀
Resumen ejecutivo para el Director de Ingeniería:
Netlify Drop para hoy mismo. GitHub Pages para la infraestructura permanente de la cátedra. Dominio propio (o subdominio UBP) cuando quieras la imagen institucional. Todo costo $0. Tiempo total de setup: menos de una hora.
